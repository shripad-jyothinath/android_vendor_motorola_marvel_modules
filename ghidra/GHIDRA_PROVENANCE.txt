Ghidra 12.2 headless decompilation of the stock A171WEH.36-31 kernel modules.

Coverage:
- 292 vendor_dlkm modules + 294 vendor_boot modules = 401 unique modules
- 63,429 functions
- 3,334,193 lines of decompiled C

This directory contains only metadata and the headless scripts:
- module-inventory.tsv: per-module size, license, description, depends,
  vermagic, aliases, exported/undefined symbols
- ghidra-summary.tsv: per-module function count, decompiled line count,
  largest functions, source-path breadcrumbs, sample log strings
- scripts/: ExportDecomp.java and ExportNamed.java

The decompiled C is included in this repository under ghidra/decompiled/ at the
explicit request of the repository owner. The module set is mostly GPL/GPL-2.0
but also includes Qualcomm/Motorola vendor modules with mixed licensing. Review
the applicable module licences before redistributing or reusing this output;
it is provided here as research/analysis material for the Marvel bring-up.
